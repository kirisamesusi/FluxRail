按键映射

默认布局为上排 A S D J K L，下排 Z 在 S 下方、M 在 K 下方。允许多个槽位设置成同一个键。

按键灯

支持即按即亮、单色常亮、幻彩常亮，默认亮度 50%。

氛围灯

支持幻彩常亮、单色流光、跑马灯，默认亮度 50%。

Web Serial 需要在 http://localhost 或 https 下打开页面。页面每次连上设备都会重新读取主控里的当前配置。
