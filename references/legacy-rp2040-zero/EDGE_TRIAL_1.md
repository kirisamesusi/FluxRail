# ARC-2 边缘优化试用版 1

固件标识：`hall-edge-trial-1-20260915`

## 刷入与首次对比

1. 使用 `ARC2-edge-trial-1-rp2040-zero.uf2`。这是微雪 Waveshare RP2040-Zero 的固件。
2. 用原网页的 **UF2 Boot** 进入引导模式，或按住板上的 BOOT 按钮再连接 USB。
3. 将新版 UF2 复制到出现的 `RPI-RP2` 盘，设备会重新启动。
4. 第一次先沿用原校准、原倍率和原限位，比较左端、右端的慢移、静止和反向，不必立即重新校准。
5. 若效果更差，可同样刷入 `ARC2-original-20260504.uf2`。它是项目附带的旧 UF2 原件，没有重新编译。

普通刷入没有擦除 EEPROM 校准区，新版也没有修改保存结构或版本号；已有合法配置会继续读取。
如果随后手动重新保存了校准，刷回旧 UF2 并不会自动撤销这些校准值。

## 本版修改

- 保留四传感器加权位置主体、物理限位方式、相对鼠标输出和现有倍率。
- 将边缘补偿改为连续、单调的映射，移除根据信号强度/优势比例突然启停补偿的分支。
- 左右分别读取已保存的端点比例和交接比例。强度增益上限等旧字段保留兼容，但不参与新映射。
- 内侧归一化位置 ±0.88 区间的静态映射保持原样，边缘只做一次补偿，取消输出端重复拉伸。
- 增益校准采样约 500 ms，去掉最高和最低各一个读数后平均；每次覆盖对应传感器旧参考值。
- 校准期间换传感器、信号太弱、ADC 饱和、样本不足或波动过大时，拒绝保存，保留旧校准。
- 增益更新后将旧端点比例恢复默认，避免混用不同增益下的比例；之后可重新扫描端点。
- 端点扫描必须同时覆盖左右外侧信号区域，避免只扫中间或单边却显示成功。
- 采集增益/扫描端点期间暂停鼠标输出，按键继续扫描。重新检测到磁铁时从当前位置开始跟踪。
- 网页显示固件版本和每路增益，增加约 4 Hz 的测试记录与 CSV 导出。

本版先保留原输出死区、滤波和限速参数，便于区分边缘映射的改善与输出门槛的影响。
仍然只剩一个传感器有有效信号时，加权位置缺乏区分不同位置的信息；本版不保证解决该区域。

## 可选：重新校准传感器差异

使用测试包 `web` 目录中的网页。双击 `start-web.cmd`，保持窗口运行，再用 Chrome/Edge 打开 http://127.0.0.1:8000。
本机项目也可执行 `python web/serve.py`。若端口已被原网页占用，请先关闭原网页服务器。

1. 将磁铁完全移开，点击“保存空磁场基线”。不要在磁铁仍靠近传感器时执行。
2. 同一磁铁保持相同高度和朝向，依次放到各传感器上方。每次点击“采集当前传感器”，静止至少半秒，等状态栏提示保存或拒绝。
3. H1 是 GP26（最右），H2 是 GP27，H3 是 GP28，H4 是 GP29（最左）。四路都应重测一遍；同一路可以再次覆盖。
4. 若当前限位允许到达两端信号区域，点击“端点扫描”，在 8 秒内缓慢往返覆盖两端。短限位不能覆盖时跳过；不要强行越过限位。
5. 基线、成功的增益采集和端点扫描会自动保存；无需每次重复点击“保存校准”。

## 建议反馈

先用原倍率做以下动作，各重复三次：

- 中间 → 左端附近慢移 → 停 3 秒 → 向右返回。
- 中间 → 右端附近慢移 → 停 3 秒 → 向左返回。
- 在中间和左右边缘分别快速左右反向。

反馈哪侧更明显、静止抖动是否减少、反向是否仍黏住，以及实际物理行程。
可以“开始记录测试”，完成动作后“停止记录”并导出 CSV。此记录约 4 次/秒，只适合趋势分析，不能证明毫秒级延迟或捕捉每次短促抖动。

## 编译配置

- Arduino-Pico (Earle Philhower)：6.1.0
- FQBN：`rp2040:rp2040:waveshare_rp2040_zero:usbstack=tinyusb,freq=125,flash=2097152_0`
- CPU：125 MHz；Flash：2 MB，无文件系统；USB：Adafruit TinyUSB
- Adafruit NeoPixel：1.15.5
- Adafruit TinyUSB：核心自带 3.7.7
- GPIO 及灯珠顺序沿用 BoardConfig.h，氛围灯为 GP10。旧 README 中 GP8 描述已过时。

旧 README 没有记录准确核心版本，因此本版使用本机新安装的 6.1.0，未声称完全复现旧编译环境。
编译结果：程序 98,644 字节；全局 RAM 18,136 字节。

```powershell
& 'C:/Program Files/Arduino IDE/resources/app/lib/backend/resources/arduino-cli.exe' compile --fqbn 'rp2040:rp2040:waveshare_rp2040_zero:usbstack=tinyusb,freq=125,flash=2097152_0' --config-file 'C:/Users/admin/.arduinoIDE/arduino-cli.yaml' --output-dir './dist/rebuild' './firmware/RP2040RhythmControllerEdgeCalibrated'
```

## 已完成验证及限制

- 微雪 RP2040-Zero 目标编译成功。
- 对实际 ARM 编译后的 EdgeResponse.h 执行 30,000 个位置测试点：多组端点参数下连续、单调、有界，内侧映射不变。
- 对实际增益采集函数进行模拟时间/ADC 测试：正常覆盖较低旧值、重复点击、换传感器、饱和、样本不足、弱信号、波动拒绝。
- 新旧 UF2 的块编号、魔数、RP2040 family ID、Flash 地址范围校验通过；写入范围不包含 EEPROM 区。
