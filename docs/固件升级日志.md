# 固件升级日志

规则（用户 2026-10-11 确定）：**每次有改动并重新编译固件，都按一次升级算**——升 `firmware/FluxRail/src/common/FirmwareInfo.h` 的 `FLUXRAIL_FIRMWARE_VERSION`（版本只在这一处改），并在本文件最上方新增一条，写清改了什么。UF2/ELF 文件名带该版本，网页 UF2 检查读文件内的版本头。没有改动、只是重编译同一份源码时不升版本（同版本重编译按 [运行发布](../RUN_INTEGRATED.md) 分目录保留）。

每条记录：版本、日期、改动内容、涉及文件、兼容性/迁移、验证状态（编译、ARM模拟、主机、实板分开写，没有证据写“未做”）。

## 0.10.3（源码已升版；2026-10-11；未编译、未刷机）

**改动**
- 模板名支持 UTF-8（中文等）：名称为合法 UTF-8（1～3 字节序列），总长 ≤ 31 字节；拒绝控制字符、DEL、C1、零宽/双向控制字符、引号、反斜杠。
- CDC v1 线路仍为纯 ASCII：`create_profile`/`rename_profile` 的 `name` 以 JSON `\uXXXX`（含代理对）传输，固件解码为 UTF-8；回复时再转义。

**涉及文件**：`config/ProfileManager.cpp`（`validName`）、`protocol/Json.h/.cpp`（`Json::utf8Value`、`JsonWriter::name`）、`protocol/ConfigProtocolDevice.cpp`（create/rename 解码与两处输出）、`common/FirmwareInfo.h`（版本 0.10.2→0.10.3）。

**兼容**：名称仍存原 32 字节槽，schema 与 Flash 布局不变；既有 ASCII 名（含最长 31 字符）全部仍合法；配置快照/导入导出格式不变。旧固件（≤0.10.2）会拒绝中文名，网页默认新建名仍为 ASCII `Custom N`。

**验证**：x86 主机测试 96 项/0 失败（[证据](../tests/integration/utf8_name_2026-10-11/README.md)）；Web 81/81（含 `asciiJson` 往返与名称规则）。**ARM 编译、UF2 识别、实板创建/改名/保存/断电重读均未做**，步骤见[窗口必读“待办”](FluxRail_开发交接_窗口必读.md)。实测通过后在本条追加结果与证据目录。
