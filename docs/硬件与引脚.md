# 硬件与引脚

更新：2026-10-05。以现行[BoardConfig.h](../firmware/FluxRail/src/board/BoardConfig.h)和2026-10-02网表提取为依据。详细器件、PCB坐标、USB/电源/Flash接线见[硬件原始提取稿](archive/2026-10-05/handoffs/rp2040_kb_firmware_notes.md)；其早期“滑轨相对移动”建议已被绝对语义覆盖。

## 板型与容量

正式目标自绘`rp2040_kb`：RP2040、12MHz晶振、W25Q32JVSSIQ（32Mbit＝4MiB）。当前历史实测使用用户确认的2MiB裸板，未测正式4MiB目标及最终电气。已有裸板保存记录不能证明4MiB配置分区在最终板上通过。

固件板型识别`fluxrail-rp2040-4mib`；正式构建4MiB noFS、125MHz、TinyUSB，boot2选项`boot2_w25q64jv_4_padded_checksum`是当前构建契约，不等于网表Flash型号为W25Q64。不得将目标GPIO与旧RP2040-Zero配置混用。

## 应用引脚

| 功能 | GPIO / 外设 | 硬件语义 |
| --- | --- | --- |
| BT1～BT10 | GP0～GP9顺序对应 | 接地低有效、输入上拉；BT10/GP9兼启动恢复 |
| 十键灯链 | GP10 | `BT9→BT8→BT7→BT6→BT5→BT4→BT3→BT2→BT1→BT10`，用户已确认顺序；当前GRB配置，实际色序未验 |
| 独立模式灯 | GP11 | 单灯，不是键灯链第11颗 |
| H1/H2/H3 | GP26/27/28，ADC0/1/2 | RP2040封装脚38/39/40；左/中/右，三路共同测一个磁铁 |
| U4 / 旋钮1 | SPI1，DO12 / CS13 / CLK14 / PUSH19 | 24bit SSI；无MOSI；PUSH高有效 |
| U5 / 旋钮2 | SPI0，DO16 / CS17 / CLK18 / PUSH20 | 不初始化默认TX19，避免占用PUSH1 |
| BOOTSEL / RUN | QSPI_SS / RUN专用路径 | 不属于普通GPIO；BOOTSEL为ROM恢复入口 |

灯链数组采用BT零基索引`{8,7,6,5,4,3,2,1,0,9}`；物理左右排布用于页面与彩虹空间顺序，不能把两种顺序强行合并。键灯5V供电、GPIO3.3V直驱路径，需要在最终实板核对灯输入电平和供电。

三霍尔相对H2的PCB器件原点约为-33.75/0/+33.75mm，器件原点不等于磁敏感区与实际磁铁行程。滑轨100mm、两限位内移7.5mm、限位参考间距85mm，磁铁中心可动约80mm仍是估计；10×5×3mm磁铁的高度和极向需实物记录。

## 旋钮主板与小板脚序

FPC1↔CN1、FPC2↔CN2按信号连接，两端同号直连不成立。

| 信号 | 主板FPC脚 | 小板CN脚 |
| --- | ---: | ---: |
| 3.3V | 1 | 1 |
| PUSH | 2 | 5 |
| DO | 3 | 4 |
| CLK | 4 | 3 |
| CSN | 5 | 2 |
| GND | 6 | 6 |

FPC7/8也接地；触点方向、同面/异面线缆及转接换序需实物核对。MT6701 MODE接高、SSI而非机械AB边沿编码器；磁环、气隙、同轴性和复位结构尚未完成最终验证。

## Flash边界

代码区相对Flash`[0,0x3FB000)`；配置A`[0x3FB000,0x3FD000)`、B`[0x3FD000,0x3FF000)`，各8192B；最后`[0x3FF000,0x400000)`为未使用EEPROM区。正式构建程序最大值4173824。分区必须经链接与运行检查，不能用IDE默认分区覆盖保存区。
