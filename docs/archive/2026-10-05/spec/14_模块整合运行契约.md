# 模块整合公共运行契约

2026-10-03，北京时间。整合窗口负责 app/realtime/common/usb/protocol 和整合测试；hall/knobs 算法及 schema2 逐字段持久化格式不变。

1. common/MotionTypes.h 的 AcquisitionConfig 是活动 Profile + 全局校准的唯一不可变采集投影，不是第二套 Profile/存储格式。配置命令沿现有 ConfigMailbox 发送：PauseApply 在核心1暂停全部发布及过滤PUSH后ACK；核心0收到ACK后清模块队列和路由待发量；Resume 在核心1实际应用 Hall/Knob/Calibration 并重建参考后ACK。网页成功响应须等待此完整过程。
2. 公共 Acquisition 复用模块现有 SPSC 边界队列，不建立第二级高频 MotionRecord 队列；Hall Estimate 的 p 是物理归一化，output 已含倍率/反向/范围。Knob Motion 的 delta_counts 是带小数的分时相对量。所有输入检查 revision/epoch，诊断由核心1复制成低频 SPSC 值，不跨核读模块引用。
3. 来源策略是 D12/D13 工程起点：X 在有效滑轨和X旋钮之间按物理活动接管，当前来源活动时保留，静止 idle_us 后允许其他活动者接管；无当前源时同时活动按 simultaneous_hall_first；同轴两旋钮先动者持有，编号0为同批平局优先。Y独立。滑轨单用或首次恢复直接提交当前绝对位置；背景旋钮分时增量丢弃并计量，不补历史。接管只清对应轴余量。
4. 普通鼠标沿既有第二HID实例扩展两个Report ID：ID1三按钮+signed16相对X/Y；ID2标准绝对XY（u16各0..32767）和恒释放的兼容按钮字节，两者payload均5字节。真实按钮仍只由ID1拥有。2026-10-04用户确认无需主机助手，Y初始中点16384，此后Hall仅替换X并携带保留Y，不能每次重置Y。Hall启用时旋钮相对增量累积到本设备逻辑XY，每count=32逻辑单位，边界夹紧；关闭Hall保持原相对输出。初始XY均中点，未校准Hall不输出；只操作Y时可用初始逻辑X。配置/保存/断连恢复保持坐标，新启动重新初始化；外部鼠标位置不回传。USB NKRO实例、唯一栈/回调、IO4人格不变，Windows启动/按钮交互/游戏须专项实测。
5. CDC v1/scope=device_schema2 不变，新增 get_motion/get_calibration/calibration_start/reference/node/begin_sweep/finish/cancel 和 enter_bootloader，同一 bounded JSON路由；能力依实际整合声明，明确 host/game 未验证。采用请求/应答轮询而非主动事件以兼容现有串行客户端，诊断10～20Hz，USB与采样不依赖网页。校准 start 先全局暂停握手，随后只抑制Hall、其他输入继续；人工毫米标签/移磁铁必须用户确认。校准完成复制候选到唯一 DeviceConfig，递增 revision/generation，再次完整ACK，显式save才持久化；取消/失败保留旧校准。
6. 保存/冷切换/UF2均沿既有维护释放/USB真正完成门槛。UF2响应传输真正完成后才进ROM，不自动上传UF2。校准运行时拒绝修改配置/保存/冷切换，状态和校准命令仍可读。
7. 网页必要接线仅限 schema2 握手/快照、真实诊断及校准/更新适配，不改原有业务算法或视觉。IO4功能表按设备读回，使用现有set_io4_bindings显式应用；USB冷切换使用已有保存/重启命令。新设备身份清除页面选择缓存与旧遥测。schema1旧归档仍允许按唯一公共迁移规则导入。

## 0.10.1共享运动端点补充

MotionSink::absoluteWithY是可选原子接口；普通后端在同一绝对报告提交Hall X与Y增量，IO4不使用。MotionRouter先合并相邻同向段以匹配1ms端点容量，反向段不跨越、不抵消；USB忙或拒绝时只整理队列，不扣量/改坐标，成功才消费。没有联合接口的后端继续原轮换。旋钮算法仍产生相对count，普通绝对模式的屏幕单位转换仅在NormalHid；默认1024counts/圈约覆盖一屏，现有gain/counts_per_turn有效。真实边界/手感及高反转负载待实测。

异步传输失败/断连后，普通后端在恢复完成且流可用时重发已提交的缓存XY；重发幂等，不重复增加Y，无已提交坐标不伪造初始运动。上述“模式切换保持Y”指运行时Hall开关/模板；NORMAL/IO4身份冷切换会重启，按新启动初始化Y，不跨重启持久化。
