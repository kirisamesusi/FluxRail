# FluxRail 旧项目审查与来源

版本：v0.4 · 初审：2026-10-02；源码核对/整理：2026-10-03。旧固件内容原样保留；只整理位置及参考范围，未执行第三方固件。行号以保留快照为准。本文件是审查证据，产品需求见[用户版](../handoffs/FluxRail_需求总览_用户版.md)。

## 1. 同键重复映射：旧实现与新需求不同

优化版rebuildKeyboardReport第1054～1060行清bitmap后，对按住来源OR；sendKeyboardAndMouse第1396～1408行比较状态发送。原版original-source.ino第1070～1076、1370～1382行同样处理。

以A为例，两个A来源仅占一个bit，第二个来源按下不会产生新DOWN；其他相同键盘键也是同样处理。20ms keepalive重复相同状态不构成UP/DOWN。**旧实现不满足K05“重复映射同一键盘键时，每次物理DOWN重新触发目标键”**，FluxRail须新增目标UP/DOWN可靠队列。不同usage集合思路可参考，修饰键按标准字段处理。具体动作表在[模块1](02_模块1_键盘与灯光.md)。

## 3. 功能保留与淘汰

| 旧功能 | 当前处理 |
| --- | --- |
| 消抖/键位编辑、NKRO位图 | 扩十二路，标准修饰状态、重复重触发 |
| SOLID/PRESS/RAINBOW | 保留含义，持续模式名单另定、首版计划逐键色、统一50%限制 |
| ambient八灯与SYNC跟随 | 新板无该灯链，不迁移；GP11改模式指示 |
| 空场/增益/端点/中心、AUTO/RISE/DROP/FLIP | 保留功能含义，三路绝对标定；polarity与invert分开 |
| 校准拒绝/取消/旧结果保护、失信号恢复 | 保留可靠性原则，新绝对/相对来源分别恢复 |
| 每SET自动commit、GET隐式开遥测 | 不迁移；显式保存，配置读取/诊断订阅分开 |
| 单循环2000ms watchdog | 双核健康联合检查，超时参数另定 |
| BT1+BT8诊断BOOT组合 | 不作为新默认；游戏可能同时按A和分号，恢复入口另定 |
| 旧四霍尔相对逻辑/常量/EEPROM | 不直接迁移，新schema和绝对位置语义 |
| 旧IO4及SDK/PN532无关依赖 | 留失败关键样本，不作成功基线 |

旧README部分路径/氛围灯GP8已过时；实际BoardConfig和EDGE_TRIAL_1记录GP10，以源码为准。旧编译结果属于旧板历史，不是FluxRail验证。

## 4. 本机Arduino核心与库

本次审核：Arduino-Pico **6.1.0**，路径C:/Users/admin/AppData/Local/Arduino15/packages/rp2040/hardware/rp2040/6.1.0；Adafruit TinyUSB **3.7.7**，NeoPixel **1.15.5**。原样[USB审核快照](../../../../references/arduino-usb-audit/README.md)已保存，安装库未修改。

| 源码 | 证据 / 影响 |
| --- | --- |
| HID_Keyboard.h / Keyboard.cpp | 普通KeyReport keys[6]，不能满足K01；无本项目可靠边沿队列 |
| Mouse.cpp | limit_xy裁剪，ready才发、move无成功返回；不能充当无损累积层 |
| SPI.cpp | setTX支持NOPIN，begin不复用NOPIN TX；必须禁SPI0默认TX19，避免PUSH1冲突 |
| EEPROM.cpp | commit关中断/暂停另一核/擦4096字节再写；维护中不能承诺实时采样 |
| tusb_config_rp2040.h | CFG_TUD_HID默认2，endpoint buffer64；实例数需固定构建，非无限 |
| TinyUSB HID接口 | 有setReportDescriptor/ready/sendReport和多实例回调基础；不等于已编译/枚举 |
| core main.cpp | setup1/loop1与独立栈基础；setup前自动USB需专项适配 |
| NeoPixel.cpp | show外层noInterrupts，即使RP2040内部用PIO；PIO不自动证明非阻塞 |

USB启动重置/默认CDC、32字符字符串、强回调所有权及两种OUT形态的完整分析见[Arduino IO4审核](09_IO4兼容与USB冷切换.md)，避免在本文件重复维护结论。
