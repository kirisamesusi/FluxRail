# IO4 软件契约（schema 2）

2026-10-03。实现目标及工程起点；编译/模拟/实板/游戏状态以 IO4 进度与验证快照为准。保留唯一 USB、DeviceConfig、ConfigStore 和 ConfigCoordinator，不修改 hall/knobs/web 算法。

- 启动身份 0=NORMAL_NKRO，1=IO4。当前身份本次启动固定；RAM 请求、已保存身份分别报告。纯 HID IO4 默认无 CDC；固定构建宏 FLUXRAIL_IO4_CONFIG_CDC=1 仅为独立兼容性候选，未经游戏验证。正常双向配置路径：普通 CDC 设置启动模式→显式 save→reboot；纯 IO4 先按启动恢复键进入普通应用→设置普通→save→reboot。恢复不覆盖保存的模式/模板/校准。
- 工程恢复键为 BT10（source9/GP9），可由 board 配置更改；仅首次连接前上拉 GPIO 有界采样，按住键并复位/上电强制普通。不是游戏长按组合，BOOTSEL 仍为 ROM UF2 最后恢复入口。
- 每模板增加 io4_bindings[12]，固定 source0..11。功能 enum disabled0、left_a1、left_b2、left_c3、right_a4、right_b5、right_c6、left_menu7、right_menu8、left_side9、right_side10、test11、service12。按来源 OR 持有，Side 协议低有效，空闲 sw0=0x4000/sw1=0x8000；电气层不在后端再反转。默认工程布局 BT8/7/6 左ABC、BT4/3/2 右ABC、BT5/1 左右Menu、BT9/10 左右Side，P1/P2 禁用。此布局不是用户确认的物理音击布局。Test sw0 bit9、Service bit6 独立可配。
- schema2 payload 头保持18字节，每个旧329字节 Profile 后追加12个功能 u8（共341字节），校准域不变。schema1 原字节格式不变；只读迁移所有旧字段/ID/next_id/活动/校准/版本，并补默认 IO4 表。迁移不写 Flash，后续显式 save 写 schema2。未知 schema 和 schema1 非普通模式拒绝。header schema 必须与 payload schema 匹配；两槽分区/CRC/commit 最后写不变。
- 身份 VID/PID=0CA3:0021，bcdDevice=0x0100，SEGA manufacturer、真实芯片 unique serial。HID接口板名完整93 ASCII字符（含尾分号），USB product为同一板名去掉尾分号的92字符；固定SEGA835Lib按八个分号域解析product，接口保留固定参考原串。两种字符串分开保存；私有库UTF-16上限126字符，正式ELF回调实测软件长度无截断，不构成主机识别证明。普通模式保留原VID/PID、manufacturer/product及serial。
- IN ID1 +63 payload=64，总字段 ADC8/spinner4/coin2/switch2 u16 LE，system/usb u8，reserved29全0。OUT ID0x10+cmd+62=64。控制回调 id0x10/63 字节，中断 id0/64 且首字节0x10；仅 instance0/OUTPUT 接受。非法统计且无状态修改。GET_REPORT 输入返回当前63字节按请求截断；OUTPUT返回最后一个已支持命令，FEATURE拒绝。
- 初始化采用本地 segatools/ongeeki 固定参考的工程行为：0x02启动；0x01/0x02→0x30；0x03→0，coin清零。0x01 payload[0] 以100ms为单位，0关闭超时；0x02保存采样计数参数，固定1ms报告，不伪装硬件多样本平均。超时回0x02、灯主机覆盖失效；下一条初始化命令恢复。原机参数单位/状态位意义仍待真实抓包。0x05/PWM、0x85更新及未知命令拒绝统计，绝不进入UF2。
- 0x04 前4 payload字节按位串 MSB-first（reference ntohl 路线），18个RGB通道参考排列1/0/3/5/4/2/8/6/7/11/9/10/14/12/13/17/15/16，对应左ABC/右ABC功能绑定的物理BT；只覆盖六功能键，其他灯本地控制，主机覆盖与本地效果共用已生效模板enabled/brightness_level，0关闭/100实际50%；最终公共127/63限幅及已确认链序不变。主机覆盖直到断连、超时、配置/维护清理；GP11首次配置确认后显示IO4品红身份工程色，独立开关/实际25%保持，不改模板保存色。位序及优先级不是产品/实板确认。
- ADC0由模块2已应用 invert/gain/range 的 output0..1 绝对值直接转换 round(output*65535)，物理左0/中约0x7FFF/右65535，右到左 lever 增加（lever=0x7FFF-ADC0）。失效保持最后有效坐标；启动/维护/断连中心0x7FFF，恢复接当前值。公共边界校验 revision/epoch/finite/valid；不写 spinner，不积分、不二次反转。正式App未调度模块2/3，能力继续 false；模拟替身只在 tests。
- USB清理在mutex忙时登记待办并在下一次后端服务完成；profile切换返回成功后公共握手才继续，detach在同一mutex内检查实际端点已完成。
- IO4 输入保序忙时不消费边沿；完成/失败/断连可诊断，恢复只重建当前状态，不补离线动作。维护调用既有 PauseApply/ACK/清旧流/释放→实际USB完成→Flash→恢复→Resume/ACK，IO4只等待注册的一个端点。普通NKRO/鼠标/同usage物理DOWN重触发不变。
- reboot_to_saved_mode 带 expected_revision 与 target；要求完整确认且当前revision已保存、目标等于已读回模式、上次维护无失败。暂停/释放→等待端点及CDC成功应答真正完成（FIFO复制与总线完成分开）→detach→250ms工程间隔→应用reboot。暂停/恢复/应答/断连/超时失败禁止detach/reboot，恢复输入并提供读回路径；间隔仍待主机实测。

影响模块4：schema2/独立IO4功能表/三模式状态及新命令，按实际能力显示；本轮不修改网页。模块2/3继续交值对象与物理数据，App采集接入及完整运动ACK另阶段，不要求改算法。
