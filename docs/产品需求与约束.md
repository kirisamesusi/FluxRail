# 产品需求与已定约束

更新：2026-10-06。需求编号继续沿用旧用户版K/L/H/R/W/P/U/Q/G，详表见[用户主需求原稿](archive/2026-10-05/handoffs/FluxRail_需求总览_用户版.md)。实现状态见[验收状态](测试状态与待验收.md)，产品目标与测试通过分开记录。

## 产品范围

RP2040控制器，包含十键、三颗49E共同测一个磁铁的滑轨、两MT6701旋钮及两PUSH、十键灯和独立模式灯；一个Web页面管理配置。面向SDVX、音击、In Falsus及普通多K，具体游戏版本/正式键位与性能容差需在验收时记录。

## 滑轨与旋钮灵敏度（2026-10-06）

用户已要求三处统一1.0～10.0、步进/显示0.1，5.0等效原倍率1，低值降低响应、高值提高响应。采用线性实际倍率=灵敏度/5；不是把旧gain1直接显示为新1。旧配置无法准确用新刻度表示时继续保留，明确编辑才替换。完整协议、schema2及算法仍使用实际倍率，详见[公共契约](公共架构与配置契约.md)及[Web验证](../web/tests/sensitivity-2026-10-06/README.md)。这项界面决策不改变物理校准、运动单位或构成实际游戏手感验收。

## 普通鼠标当前决策

2026-10-04用户已选择标准绝对XY且无需主机助手。本设备逻辑XY启动于16384（0..32767），Hall只替换X，旋钮Y累积后由后续Hall报告携带。运行时模板切换、保存和断连恢复保留逻辑Y；固件重启（含USB身份冷切换）重新从中点初始化。外部鼠标改变的系统Y不会回传本设备。

Hall开启时旋钮仍产相对count，后端把它积到绝对坐标，每count为32逻辑单位；Hall关闭时输出相对鼠标。两个Mouse集合的真实按钮交互、实际位移与游戏兼容仍待验收。不能恢复早期“仅绝对X无Y”或每次报告固定Y的方案。

## 现行默认与待确定项

四预置ID1 SDVX、2 ONGEKI、3 IN FALSUS、4 MULTI K，首次活动4；音击双旋钮默认关闭；PUSH初始禁用。预置不能删除，名称/参数可改，恢复预置保留全局校准。已保存/导入的颜色以设备读回为准。

灯效当前实现STATIC/BREATHING/COLOR_CYCLE/RAINBOW_WAVE/PRESS；四预置指示色青/橙/紫/绿、IO4身份品红是工程默认，最终产品色值尚待确认。默认映射和已定亮度限制不因颜色待定而改变。

仍需确定或实测：重复鼠标按钮策略、各游戏默认值、同轴与同时动作手感、实际磁铁中心行程/高度/极向/覆盖、旋钮磁环和PUSH结构、最终误差与最大延迟容差。约80mm行程只是估计。历史D01～D24的“待实现”很多已被当前实现覆盖，未决项以[测试与接手表](测试状态与待验收.md)及模块文档为准。
