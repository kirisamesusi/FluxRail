当前Web中，version节点显示初始说明、连接/版本比较/模拟/换设备提示或错误；result节点保留文件详情，或者显示文件错误/清空后的选择说明。此前测试要求所有动态消息都在result，并要求version始终固定，因此10/07出现两项失败。本次按当前分工调整断言，没有删除测试或改为跳过。

保留并执行的检查：

- 有效UF2识别后的文件名、版本、板型与块数/字节数。
- 先选文件再连接、断连、同版重连、设备序号变化及重新选文件；连接变化保留文件详情，提示按当前会话更新。
- 模拟身份与不能比较实际设备版本的提示，不能冒充可升级/同版。
- 无效与过大文件拒绝，旧候选/序号清除，错误不能显示旧识别通过结果；断连仍保留文件错误，取消选择清除候选/错误并恢复初始状态。
- 底层结构、地址/保留区、损坏/板型拒绝及版本比较的原有六项检查保持不变。
