进入下载模式并更新

  1. 先保存需要保留的设置。
  2. 点下面的按钮进入 UF2 下载模式，电脑会出现 RPI-RP2 磁盘。
  3. 手动复制匹配此设备的 FluxRail UF2 到磁盘，网页不传送固件。
  4. 完成后重新连接，核对固件版本并检查功能。

按住键盘上的 BOOT 接入 USB 后松开，也可进入下载模式。
