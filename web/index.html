PROFILES

模板管理

选择要编辑的模板。预设可另存为自定义模板。

点选预设会恢复默认设置，预设不能覆盖或改名。“保存到当前模板”可保存自定义模板；选中预设时会另存为新模板。要让设备使用该模板，请另点“设为活动模板”，再应用并保存。

KEY MAPPING

按键映射

从菜单选择键盘或鼠标动作，也可监听键盘录入。

连接设备后读取十二路键位，或在实验性功能中打开模拟演示。

面板布局：上排左侧 BT8～BT5，右侧 BT4～BT1；下排 BT9 / BT10。P1 / P2 为旋钮按压，分别位于布局左上 / 右上。

允许重复映射。监听时 Esc 取消；Esc 键可从菜单选择。重复键按下会重触发，可能短暂中断原有长按。

LIGHTING

灯光设置

设置灯效模式、亮度及全局颜色。

逐键颜色在实验性功能的灯光分组中设置。

HALL SLIDER

滑轨设置

配置滑轨输入开关、输出方向和中心灵敏度。

H1H2H3✿

灵敏度影响输出位置覆盖范围。详细范围与共享校准在实验性功能中。

KNOBS

旋钮设置

模拟旋转，观察当前位置、累计圈数和输出方向；修改输出轴、方向及灵敏度。

本地模拟用于预览灵敏度与方向；实际设备旋钮状态位于设备状态首页。U4 / FPC1、U5 / FPC2 对应旋钮小板，左右位置需根据实际装配确认。输出范围、PUSH 过滤与来源接管在实验性功能中。
