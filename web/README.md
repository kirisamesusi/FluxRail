# FluxRail Web配置工具

更新：2026-10-08（北京时间）。当前原生ES模块单页配置工具，开发目录为 `web/`，开发与待验收分支为 `test`。页面规则按当前源码整理，UF2软件测试按用户本次要求适配当前Web显示方式。

完整接手文档：[05 Web配置工具](../docs/modules/05_Web配置工具.md)，包含文件职责、草稿/应用/保存/激活、预置保护、连接锁、测试和备份恢复。新窗口先读[统一交接](../docs/FluxRail_开发交接_窗口必读.md)，实板状态见[测试表](../docs/测试状态与待验收.md)。

朋友测试站部署见 [Ubuntu / HTTPS / GitHub Actions](../docs/Web部署_Ubuntu与GitHubActions.md)：Nginx独立站点配置，`test`分支测试通过后上传静态运行文件；服务器无需Node常驻服务。部署文件在 `web/deploy/`，工作流在 `.github/workflows/deploy-web.yml`。

已完成基础环境后可使用 [交互式部署包](../outputs/FluxRail-Ubuntu-Setup-2026-10-08-r2.tar.gz)，解压执行 `sudo bash setup-fluxrail.sh`；[使用说明](deploy/README.setup.md)。需要打包新的本地Web快照，根目录运行 `python web/deploy/package-setup.py outputs/新的文件名.tar.gz`，已有包不覆盖。

## 启动与页面入口

根目录运行 `node web/server.mjs`，访问 `http://localhost:4174`；Node>=20，无npm install与打包步骤。在 `web/` 执行 `npm test` 跑package.json列出的九套软件测试。生产连接使用桌面Chrome/Edge的Web Serial，需要localhost或HTTPS。

| 导航模块 | 地址片段 | 当前用途 |
| --- | --- | --- |
| 设备状态（默认首页） | `#device-status` | 设备信息、活动/编辑模板、按键/滑轨/旋钮概况及可展开输入状态 |
| 按键映射 | `#keyboard` | 十二来源普通键鼠动作与键盘监听 |
| 灯光设置 | `#lighting` | 灯效与亮度 |
| 滑轨设置 | `#hall` | 启用、方向和中心灵敏度 |
| 旋钮设置 | `#knobs` | 两旋钮配置及本地旋转预览 |
| 模板管理 | `#profiles` | 预置、自定义模板与活动模板管理 |
| 固件更新 | `#update` | 本地UF2识别、版本比较、下载模式入口 |
| 实验性功能 | `#experimental` | 模拟演示、完整快照、校准、高级参数、原始状态记录及IO4编辑 |

首页显示当前会话读回的型号、固件/协议、唯一序号、当前USB模式、设备RAM启动模式、活动模板及修订号。设备活动模板与页面编辑模板分开显示；首页开关与设置页共用网页草稿，改动后经顶部“应用并保存”提交。断连保留的信息标为“上次读回”，不能当作在线状态。旧 `#diagnostics` 会进入首页并展开输入状态。

模拟演示入口是 **实验性功能 → 临时测试 · 模拟演示**（可直接访问 `#experiment-device`），已从设备信息区域分离。启动模拟后，顶部与侧栏仍标明模拟身份，首页显示模拟会话的信息。隔离schema1对象用于界面/协议演示，保存只改模拟对象；旋钮页的本地旋转预览是另一项功能，不建立设备会话。生产Web Serial读写已有裸板证据，完整功能和最终硬件仍待验。

## UF2 当前显示与测试口径

用户2026-10-08要求测试按当前Web适配，本轮未修改页面代码。当前 `#version-result` 在无候选/无错误时显示“选择UF2后自动识别固件并比较版本。”，选文件后显示连接、版本比较、模拟、设备变更提示或文件错误；错误样式挂在该节点。下方 `#uf2-result` 显示读取进度、文件名/识别版本/板型/块数与字节数，或文件错误，取消选择恢复选文件说明。连接变化更新比较提示并保留文件详情。`#current-firmware` 单独显示当前真实/模拟版本，`#update-cap` 单独说明设备下载模式能力。

“模拟会话不能用于比较实际设备版本”是UF2结果提示，和模拟入口移到实验性功能没有冲突。选文件仍自动识别；模拟设备版本不能用于真实设备升级判断。网页检查不刷写，进入下载模式后仍需用户手动复制UF2，再重连核对版本。

本轮保留两项控制器测试及其功能检查，断言位置改为当前两区域分工；UF2专项8/8、完整Web73/73通过，见[10/08测试适配记录](tests/uf2-current-web-2026-10-08/README.md)。此前[10/07复核](tests/web-docs-sync-2026-10-07/README.md)的6/8、71/73失败结果仍保留。之前截图的“上方始终固定、所有动态内容在下方”没有由此次测试适配实现，也不属于本轮通过结论；10/06固定说明通过记录仅代表当时快照。
