# FluxRail Web 文案审查

这份审查整理可供空壳页面套用的替换建议，没有修改 `web/` 或现有文档。第二轮根据 `tools/source-shell.html` 与已生成的 `index.html` 对照实际可见文本节点，拆开了原先跨节点的输入测试和更新步骤文案，并补充了实验性功能中的说明、标题、等待状态和设备信息标签。动态文案可用 `{name}`、`{count}` 等占位符标出变量，静态空壳使用实际出现的字面文本匹配。

审查范围：`web/index.html`、`web/src/app.js`、`web/src/config.js`、`web/src/integration.js`、`web/src/io4-editor.js`、`web/src/knob-preview.js`、`web/src/update/controller.js`、`web/src/confirmation.js`、`web/src/template-actions.js`，以及开发交接、公共架构契约、硬件与引脚、Web 模块文档。替换表覆盖静态说明、控件提示、等待/成功/错误状态和确认弹窗。

代表性修改：

| 位置 | 原文 | 建议文案 |
| --- | --- | --- |
| 操作提示 | 编辑 → 应用到RAM → 保存到设备。 | 修改后先应用到设备；要在断电后保留，再保存到设备。 |
| 模板管理 | 新建模板不会自动切换活动模板。 | 新建模板后，设备仍使用原来的活动模板；需要启用新模板时，请另外点“设为活动模板”。 |
| 滑轨说明 | 配置滑轨输入开关、输出方向和中心倍率。 | 设置滑轨开关、输出方向和中心倍率。滑块停在哪，输出位置就对应到哪。 |
| 滑轨倍率 | 小于 1 只覆盖中央 | 小于 1 时，输出只覆盖中央一段。物理滑块仍可走完整行程。 |
| 输入测试 | 短按可能落在两次快照之间；网页不据此判断漏采。 | 状态每半秒读取一次，快速点按可能看不到。 |
| 旋钮预览 | 本地模拟 · 不发送设备输入 | 页面预览 · 不会驱动设备 |
| 高级灯光 | GP11 独立指示灯暂定实际 25%，由固件单独限幅。 | 模式灯亮度最高为 25%。 |
| 更新步骤 | 出现 RPI-RP2 盘后复制正确的新板 UF2。 | 出现 RPI-RP2 磁盘后，把适用于本设备的 UF2 文件复制进去。 |
| 旋钮/游戏 | HID count 不等于屏幕像素；磁环和 PUSH 结构尚未实板验证。 | 旋钮输出的是转动增量。不同程序和系统设置会影响实际移动距离，请在目标程序中确认效果。 |
| 演示说明 | 演示使用隔离模拟端口，不代表实板验证。 | 演示只在页面中显示模拟数据，不会连接或测试真实设备。 |
| IO4 恢复 | 按住 BT10 复位或上电可返回普通模式。 | 要返回普通模式，按住 BT10 后复位或重新上电。 |

关键操作区别已保留：网页修改要先应用到设备；要在断电后保留还需保存；预设另存为自定义模板，自定义模板选择后不会自动启用；滑轨位置按绝对位置输出，旋钮按转动增量输出；状态快照可能看不到快速短按；更新时需要手动复制 UF2；IO4 可通过 BT10 返回普通模式。预览、模拟数据或软件检查均没有描述成硬件验收通过。

滑轨倍率文案按当前映射含义修正：倍率小于 1 时，完整物理行程仍然可用，映射后的输出只覆盖中央一段。滑轨主介绍也说明滑块位置对应输出位置，避免被理解为机械行程调节。

`copy-replacements.json` 共 178 条替换建议，已套用到最终空壳页面；其中 89 条匹配静态页面文本，另 89 条保留为运行状态和人工合并参考。应用记录见 [applied-copy.json](evidence/applied-copy.json)，页面检查见 [preview-check.json](evidence/preview-check.json)。最终检查覆盖 8 个模块、11 个内层展开分组，以及 1440px 和 390px 窗口尺寸；未发现溢出或浏览器错误。74 个原 `web/` 文件的 SHA 保持不变。
