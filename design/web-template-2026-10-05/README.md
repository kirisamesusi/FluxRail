# FluxRail Web 固定重构模板 · 2026-10-05

这是用户选定用于下一窗口重构的当前设计模板。页面、样式、脚本及六个运行资源文件按字节复制自最终4175预览；仅独立服务器使用4176端口。生产 `web/` 及固件没有因冻结而修改，模板没有接入设备。

从仓库根目录运行：

```powershell
node design/web-template-2026-10-05/server.mjs
```

打开 [固定模板](http://localhost:4176/#device-status)。端口需要调整时用 `FLUXRAIL_TEMPLATE_PORT`。原迭代预览仍在4175，生产页面在4174，三个目录及端口分开。

## 下一窗口从这里开始

完整交接与可复制任务见 [Web重构交接](../../docs/Web重构交接_2026-10-05.md)，迭代历史见 [web修改.md](../../web修改.md)。下一个窗口沿生产实现重构：模板只提供结构、文案和交互意图，不直接替换生产HTML、不带入 `shell.js`。

本目录同时保存冻结的 `HANDOFF.md`、`CHANGELOG.md`，便于归档后查阅；仓库里的文档入口继续负责现行事实。完整包为 `design/FluxRail-Web-template-2026-10-05-v1.zip`，旁边保存压缩包SHA-256。压缩包可独立启动静态模板；交接中指向仓库生产代码、模块文档和旧证据的链接需在原仓库内查看，未把整个工程打包。

当前方案包括：设备状态首页，模板管理移到旋钮之后；去框合并页头；侧栏粉色IO4开关和确认；输入状态整合；四个标题标签移除；三个倍率尺；同宽直显校准及小字参数帮助；UF2步骤移入二次确认。表单中的示意值、禁用属性和页首“文案预览”不是生产状态。

倍率刻度1～10、初始5是设计示意，现滑轨固件上限8且默认1。交接单列了兼容与旧值处理，不能只改网页就宣称10可用，也不能自动改固件预设默认。

## 保存和核对

- `manifest.json`：固定文件的SHA-256、复制来源、冻结时生产HEAD/分支及文件一致性，脚本依赖与验证边界。固定模板后续不要覆盖；有新设计另建版本。
- `baseline/production-web-before-preview.json`：原74个Web文件的复制前哈希，只用于比较，不代表干净Git状态或正式验收。
- `baseline/production-working-tree.txt`：冻结时仓库已有修改。其他窗口成果应保留，不能按“模板完成”重置生产树。
- `copy-replacements.json`：原文/改文候选；`preview-edits.json`：过程配置，不是生产构建配置。其转换工具保留在原迭代预览 `tools/` 中。
- `reviews/`：本次文案及各轮Luna评审副本。最新交接审查与证据见本目录 `evidence/`。

固定模板以本目录HTML/CSS为准；旧记录仅供追溯，不还原被用户删除的卡片、标题标签或旧范围。源码许可沿仓库MIT及第三方声明，不改变素材、原文档或历史证据许可。

核对文件完整性用 `node design/web-template-2026-10-05/verify-template.mjs`。`check-template.mjs`是本次组装的离线浏览器检查，需额外传入Playwright模块路径；已有报告时拒绝覆盖，重新检查须传入新的绝对输出目录。后续生产回归用现有Web测试入口，不拿此空壳检查替代。

## 验证边界

冻结检查覆盖资源与文件一致性、八个模块、倍率小数、本地IO4/重启/UF2确认、取消/Escape及窄屏布局。此模板只能证明页面呈现和本地交互；未运行生产Web回归、编译固件、连接串口、保存Flash、刷写、裸板或游戏验证。

最终组装记录在 `evidence/template-check.json`：1274、390、320px共24种模块视图，10个页面/资源文件与原预览字节一致，原74个Web文件未变。文档记录在 `evidence/docs-check.json`。交接独立评审为 `reviews/LUNA_REVIEW_重构交接.md`。固定页Logo的旧模板链接、生产动态ID与锁、倍率差异均在交接中明确说明，不能据此认定已接回生产。

生产重构的软件和设备验证要求在交接文档中列出。运行时依赖仅Node.js内置模块；模板不需要npm install或打包。Playwright只用于离线检查，不进入页面或服务器。
