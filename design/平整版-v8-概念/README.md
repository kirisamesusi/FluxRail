# FluxRail 平整旋钮 v8 概念

2026-11-18 · 结构减件 + 杠杆压簧调阻尼的**概念方案**。目前只有 3D 概念模型、参数、BOM 和改动说明，还**没有** CadQuery 实体、STEP/STL、加工图，也没做实体干涉检查。正式出图前先按 [续做](续做.md) 把它转成 CAD。上一版 [v7 r2](../平整版-v7-r2/README.md) 保留不动。

每只旋钮从 v7 r2 的 59 件减到 38 件：打印件 9 → 5，螺丝五金 36 → 20。改动有四处：

- 一体轴承座：取代左右固定座和上轴承杯。
- 删掉 16 件吊挂：轴承座法兰改由原来的 4 颗底壳螺丝夹住。
- 杠杆压环 + 小压簧：取代导向压环、上 POM 托环和波簧。
- 底壳一体卡扣：取代退板挡条和它的两颗螺丝。

磁铁、POM、黄铜盘、686 高度、铝盖和帽的位置都沿用 r2。逐项对照见 [改动说明](改动说明.md)。
