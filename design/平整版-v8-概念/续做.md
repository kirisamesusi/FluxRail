# v8 概念 · 续做

2026-11-18。当前只有概念几何（[旋钮模型.html](旋钮模型.html) 里的 three.js 基本体）和 [参数](参数.json)。下一步要把它转成和 v7 r2 同级的 CAD 交付。

## 转 CAD

1. 在 `设计源/` 下新建 `build_v8.py`，沿用 [v7 r2 的 build_v7.py](../平整版-v7-r2/设计源/build_v7.py) 和 `build_r1_reference.py` 的基础件、坐标和 `audit()`：
   - 新建 `housing()`、`lever()`、`spring()`、`tray()`、`magnet_hub()`。
   - 退役 `carrier()`、`bearing_cup()`、`saddle()`、`pressure_yoke()`、`wave`、hanger 组和 keeper 组。
   - 尺寸以 [参数.json](参数.json) 为准，有冲突时以实测和整机为准。
2. 按 r2 的验证项重做：
   - 转动与行程：八个转角 × 调节 0 / 1 / 2 mm。
   - 阻尼受力与净空：压点接触面积、支点接触、弹簧井和螺丝同轴、磁隙。
   - 工具与拆装：装帽后从上方插 1.5 内六角；小板退出；上取顺序已经变了。
   - 整机：重点是弹簧井一侧和背板、顶板的净空。
3. 导出 STEP/STL、打印清单、BOM、单件下载页和 ZIP。BOM 以 [BOM.csv](BOM.csv) 为起点。

## 需要拍板 / 实测

- **压簧选型**：外径 ≤3.6，自由长 5–7，刚度 1–2 N/mm。买 2–3 种对比。
- **目标力矩**：先测 v6 / r2 现有手感和 686-2RS 的基础阻尼，再反推刚度。测法：帽上绕线，挂秤拉，力矩 = 拉力 × 15 mm。
- **铝盖**：复用 r2 的盖（轴承座加凸台嵌凹槽），还是新做无吊挂孔、带刻度的盖。
- **光轴**：新购 D 轴，还是现有圆轴磨平面。
- **法兰定距**：要不要在底壳螺丝外套金属管。
- **磁铁杯夹轴长度**：2.55 够不够。
- **杠杆压环**：在 5–10 N 下的变形和支点磨损。
- **卡扣**：割缝宽度和弹片厚度，打一个试件。
