# v7 r2 设计源重建

本目录包含 build_v7.py（r2 参数和实体）、build_r1_reference.py（独立 r1 参考）、verify_v7.py（CAD 检查）、export_v7.py（STEP/STL、DXF、CSV 和 HTML）、viewer.html（网页模板）、build_bom.mjs（BOM Excel）及冻结的 baseline/ 输入。机身基线来自 v6 采购适配。运行时只需要本包内容。

使用 Python 3.12 和 requirements.txt。在 FluxRail 本机可用 C:/Users/admin/.codex/tools/fluxrail-cad/Scripts/python.exe。从解压副本的「设计源」目录运行：

~~~powershell
python -m pip install -r requirements.txt
python verify_v7.py
python export_v7.py all
~~~

输出到当前包根目录。export_v7.py assemblies 仅导总装。models 导独立件、CSV、工艺 DXF 与 3D 网页。pages 只重建入口、采购、装配和下载页。更改几何参数后同步校对尺寸图和工艺要求。

BOM.csv 和部件清单.json 随 CAD 重建。Excel 排版的可选步骤：使用有 @oai/artifact-tool 的 Node.js 环境，运行 `node build_bom.mjs <包根目录>`。verify_browser.py 可用已有 Chromium（默认 Windows Chrome 安装路径；也可设置 FLUXRAIL_CHROMIUM）及 Python Playwright 从 file:// 执行。复核完整包可运行 python package_v7.py，它检查模型、清单、校验和与 ZIP 内容。

轴承装配里内外圈和密封为可分别检查的参考体，商品、BOM 和单件导出仍各按一个轴承计数。波簧以连续三波正弦包络表达名义高度；它不是材料、波峰形状或刚度的供应商模型。
