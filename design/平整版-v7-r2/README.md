# FluxRail 平整旋钮 v7 r2

2026-11-06 · 外部可调 POM 阻尼试装版。解压 ZIP 后双击 [index.html](index.html)，可离线看总成、爆炸和单件。上一版 v7 r1 保存在原目录。

每只旋钮的铝盖上有一颗独立的 M2×6 调节螺丝。装着旋钮帽也能从上面调。686-2RS 提供基础阻尼，螺丝推动带双导柱的压环，波簧把两片防转 POM 压向黄铜盘。盘由磁铁杯的两个键带动，可沿轴向滑移。制动压力经过螺丝、封盖、底壳和摩擦叠层闭合，轴承座负责定位。

名义螺丝行程 0.60 mm，约 1.5 圈。初版取波簧自由高 2.0 mm 作 CAD 假设，最松时约 0.05 mm 空隙，拧至名义下限时弹簧高 1.45 mm。实测自由高、摩擦力和导柱滑动决定实际可用范围。固定杯保留原 686-2RS，MR106ZZ 下轴承抬高 0.45 mm 以避开下夹轴，磁铁、轴、帽和整机开口保持原位。名义磁隙 0.60 mm。
