# v7 r2 CAD 检查

- [转动与行程](转动与行程.json) 覆盖三个调节位置和八个转角。
- [阻尼受力与净空](阻尼受力与净空.json) 检查两面 POM 接触面积、螺丝到压环、波簧、盘相对键的轴向自由、固定轴承杯及 0.60 mm 磁隙。
- [工具与拆装](工具与拆装.json) 覆盖装帽后的直柄工具、退板、轴取出和制动件上取。
- [整机](整机.json) 检查 INF 滑轨两端和音击中点。[原接口与整套上取](原接口与整套上取.json) 比较与 r1 同位的接口实体，检查九个上取高度。抽出时按 FPC 已断开建模。
- [STEP 装配](STEP装配.json)、[独立件](独立导出.json)、[离线网页](离线网页.json) 和 [包检查](包检查.json) 记录交付文件验证。

待实测项目为实际调节范围和手感、轴与键的保持力、单边施压时导柱顺滑度、POM/铜盘磨损、螺丝保持以及磁场。磁隙与接触面积为 CAD 名义值。
