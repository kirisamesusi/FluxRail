# FluxRail 配置网页 · 设计规范（2026-10-11 版）

本文是「设备状态」页定稿后的视觉与交互规范。可点击的原型是视觉的唯一依据：`prototype/index.html`（浏览器直接打开，连接按钮是模拟的，不连真实设备）。实现要点和后端改动见 `HANDOFF.md`。

**文案原则：原项目已有的文字一律沿用，不改写。** 原型里的文字分三类，见 `HANDOFF.md` 第 4 节。

## 1. 定位

- 桌面优先，不做手机适配。最小宽度 1200px，常用尺寸 1280×720、1440×900、1920×1080 都要好看。
- 风格：可爱、水色、蓝粉白。圆角大、按钮是胶囊形、阴影很轻。
- 使用者：卖家（常改灯光、按键、模板）和买家（改按键、灵敏度）。常用设置都放在首页，进阶的放「实验性功能」。
- 不引入任何外部资源（字体、图片、脚本）。字体用系统字体栈。现有 CSP 和服务器白名单保持不变。

## 2. 颜色

| 用途 | 值 |
| --- | --- |
| 蓝（主色，按钮、选中键、原生读数） | `#8FD3F0`，浅 `#BFE6F7`，底 `#EAF7FD`，线 `#CBE9F6` |
| 粉（强调，保存、灵敏度后读数） | `#F7A8C4`，浅 `#FBC5D8`，底 `#FFE9F1`，深 `#C2456F` |
| 文字 | 主 `#1F3A4A`，次 `#52707F`，弱 `#7A93A1` |
| 错误 | `#B23A48`，底 `#FBE3E3` |
| 成功 | `#2F9E6B` |
| 页面背景 | `linear-gradient(180deg,#EAF7FD,#FFF1F6)` |
| 卡片背景（不用纯白） | `linear-gradient(155deg,#FFFFFF 0%,#F2F9FD 42%,#FFF3F8 100%)` |

**蓝色永远代表「原生」，粉色永远代表「灵敏度后」**，旋钮、滑轨、图例、读数全部一致。

## 3. 形状与字体

- 卡片圆角 24–28px，按钮胶囊形（高 38–42px），输入框圆角 12–14px。
- 虚线分隔 `2px dotted #F9D0DF` 或 `#BFE3F3`。
- 字体：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei","Noto Sans CJK SC",system-ui,sans-serif`；版本号、读数、色值用等宽 `ui-monospace,Menlo,Consolas,monospace`。
- 小号字不低于 12px。

## 4. 页面结构

顶栏 → 横幅（标题 + 看板娘气泡）→ 三栏 → 状态栏。

1. **顶栏**：头像 + FluxRail；IO4 启动模式开关；三个页签（设备状态 / 固件 / 实验性功能）；连接状态胶囊；「重启设备」「连接 FluxRail / 断开」「应用并保存」。
2. **横幅**：左边标题「设备配置」和三个信息标签（设备型号、固件版本、活动模板）；右边看板娘（半身像）和说话气泡。
3. **左栏 248px**：模板列表（点选后在右栏管理）、设备信息（默认折叠）、历史操作。
4. **中栏**：设备面板（左旋钮、滑轨、右旋钮；八个按键；BT9 / BT10）和灯光设置。整个面板在可用高度里垂直居中。
5. **右栏 320px**：检查器，内容随选中对象变化（按键 / 左旋钮 / 右旋钮 / 滑轨 / 模板）；底部是键盘看板娘插画。
6. **状态栏**：左边「RP2040 · Web Serial」，右边「设备信号」选择（只在演示 / 测试时有用）。

自适应：1560px 以下、1360px 以下各缩小一档（按键、旋钮、两侧栏、间距）；超过 1800px 内容居中；高度 800 以下压矮横幅。具体数值见原型 CSS 末尾。

左栏高度由中栏和右栏决定，**不能因为展开「设备信息」让页面变高**；展开时内部滚动。

## 5. 设备面板

- **旋钮**：160px 圆形。外圈是点状虚线，粗环是蓝粉渐变，中间白色圆帽。蓝点在环上，代表原生；圆帽边缘的粉色小缺口代表灵敏度后。文字「左旋钮 / 右旋钮」。
- **滑轨**：圆角凹槽，粉色填充条（带高光和小泡泡）代表灵敏度后；蓝色圆滑块（白粗边）代表原生；上方有粉色小三角指向灵敏度后的位置。槽下面一排刻度，**不写 H1 / H2 / H3 的字**。
- **按键**：90×82px 圆角方块，顶部有高光。BT9 / BT10 用粉色。三种状态互不排斥：
  - 选中（鼠标点选）：深色描边 + 粉色光圈；
  - 按下（设备上真的按了）：下沉 3px、变白、蓝色光圈；
  - 禁用：灰色，文字写「禁用」。
- 未连接时，旋钮和滑轨的指示隐藏，读数写「暂无有效位置」。
- 连接后，设备面板只显示设备实时状态，**页面上不能拖旋钮或滑轨**。只有测试模式可以用滚轮 / 拖动模拟，转动要平滑，不能一格一格地跳。

## 6. 灯光

- 控件：键灯启用、灯效、亮度（0–100）、全局颜色。
- 灯效：常亮、呼吸、同步换色、彩虹流动、按下即亮、**自定义**。
- 选「自定义」：全局颜色变灰；每个按键在右栏单独选颜色和亮度；设备面板上每个键的右上角显示一个小圆点表示它的颜色。选其他灯效时，按键灯光那一块是灰的并写明原因（灯效和按键灯光互斥）。
- 颜色选择：**三个色球 + 一个调色盘球**。三个球默认是蓝、粉、白。用户从调色盘选新颜色，会依次顶掉第一个球、第二个球、第三个球，然后回到第一个。**全局颜色和按键颜色各用一套**，互不影响。调色盘球旁显示当前色值。
- 逐键颜色不再放在「实验性功能」里。
- 主界面不出现引导去「实验性功能」的文字。
- 左旋钮默认输出轴 X，右旋钮默认 Y。

## 7. 灵敏度

- 范围 1.0～10.0，步进 0.1，5.0 是原来的标准值。越大越灵敏。
- 控件：滑块（两端写「低」「高」）+ 数字输入框（一位小数，输入时超出自动夹到范围内）。
- 读数：旋钮显示「x.xxx 圈」；滑轨原生显示百分比，灵敏度后显示 0–1 的数值（三位小数）。

## 8. 气泡（看板娘说话）

- 位置：横幅右侧，看板娘左边，气泡尖角向右。宽 250–290px。
- 四种状态：成功（深色描边）、提示（深色描边）、有未保存修改（粉色描边，带「还原修改」按钮）、出错（红色描边）。
- 成功类提示约 5 秒后淡出，回到当前状态的常驻文字；出错不自动消失，写明原因和下一步。
- 所有提示同时写入左栏「历史操作」。
- 历史操作要写清楚**改了什么**，例如「BT5 按键动作：键盘 · F → 键盘 · G（未保存）」「滑轨中心灵敏度：5.0 → 7.5（未保存）」。连续拖动只记最后结果。
- 常驻文字：未连接「尚未连接设备 / 连接后可读取和修改设置。」；已连接且无修改「设置和设备一致」；有修改「有 N 处修改已生效，还没保存」。

### 看板娘彩蛋

右栏底部的键盘看板娘可以点。点一下，头顶冒出一个气泡，随机说一句话，约 5 秒后消失，连点不会连续重复同一句。台词放在 `mascot-lines.txt`，一行一句，`#` 开头是注释，改完刷新网页就生效。文件缺失时用内置的几句。

## 9. 确认弹窗

只用在会丢修改或不能撤销的操作上。默认焦点在「取消」，按 Esc 取消，Tab 在弹窗内循环。按钮写清后果，不写「确定」「是」。弹窗里有名称输入时，默认焦点在输入框。

具体的标题、正文和按钮沿用原项目文案，列表见 `HANDOFF.md`。

## 10. 禁忌

- 不用表情符号当图标；图标用内联 SVG，带 `aria-hidden`。
- 不用颜色单独表达状态，旁边要有文字或符号。
- 不用外部字体、外部图片、外部脚本。
- 不把保存状态只放在页脚，也不在多个地方重复同一句话（气泡、历史操作、状态栏各管各的）。
- 新增控件前先看能不能放进右栏检查器，不要再开新的顶部选项卡。

## 11. 素材

沿用 `design/asset-library/fluxrail-mizuiro/` 和 `docs/视觉素材与角色规范.md`：头像（顶栏）、半身像（横幅）、键盘插画（右栏）。素材由 AI 生成，参考漫画的画师未确认，只作参考（见仓库规范）。开源和售卖时按仓库现有的许可说明处理，不要自己改声明。
