# Web 左右布局重构与验证

日期：2026-10-04。

参考：[emil-design-eng / SKILL.md](https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md)。本轮重点采用有目的的交互反馈、避免频繁操作动画、明确过渡属性、触屏 hover 限制、减少动态效果支持。

| Before | After | Why |
| --- | --- | --- |
| 顶部横向锚点导航，全部模块纵向堆叠 | 桌面左侧模块导航，右侧仅显示当前模块 | 设置位置清晰，减少页面扫描与滚动 |
| 导航只滚动到原页面位置 | 独立 layout.js 管理片段、当前链接、焦点及深链接 | 模板编辑和实验室跳转保持可用，支持历史导航 |
| 模板按钮名称含花朵、音符字符 | 普通模板名称与功能说明，图形保留在 SVG 中 | 文字采用说明书表达，视觉仍保持水色和偏可爱风格 |
| 悬停位移，旋钮图形 280ms 旋转过渡 | 指针按压 140ms 反馈，连续预览和遥测即时更新 | 频繁输入需要及时反馈，不拖延实际读数 |
| 悬停规则直接用于全部设备 | 指针 hover 效果仅对支持 hover 的精确指针启用 | 避免触屏悬停残留 |
| 模块切换可能隐藏监听卡片 | 导航调用原有统一取消监听出口 | 隐藏的编辑器不会继续捕获键盘输入 |

左侧导航标题按用户后续要求改为“设置”，导航及模块标题中的 01–08 编号均移除；固件更新操作步骤编号保留。

## 备份和范围

修改前复制完整 web/，28 个文件与源文件逐字节一致；清单含大小/SHA-256。备份位置：backups/web-before-layout-2026-10-04/。修改范围为 index.html、style.css、src/app.js、package.json、README.md；新增 src/layout.js、tests/layout.test.mjs 和本次验证记录/截图。设备协议、序列化、固件与 GPIO 文件未修改。

## 验证

- 原有 35 项前端测试：修改前通过；修改后仍通过。
- 5 项导航测试：默认与非法片段、编辑器/草稿保留、深链接展开、历史/跳过链接、修饰键行为及监听释放。
- 浏览器模拟：BT8 从 A 监听录入 B，切换旋钮后返回仍为 B；应用到 RAM、显式保存后读回 B，草稿清除，保存状态更新。
- 旋钮模拟：顺时针一圈输入/倍率后累计值均为 1.000 圈，圈内位置回到 0.0°。
- 模板修改入口显示按键模块；浏览器后退显示模板模块。
- 默认桌面以及 820、390、320 CSS viewport 请求；分别核对无页面横向溢出。移动导航允许内部横向滚动。
- 窄屏实验室 11 个分组全部展开，input/select/pre 没有越过页面右边界。
- 控制台无 warn/error。仅模拟会话，没有打开实板串口或刷写固件。
