PROFILES

模板管理

选择预设或自定义模板，确认后保存当前设置。

4 个预置 + 自定义

四个预设模板不可覆盖或重命名，点击预设会恢复默认设置。可以修改预设设置，应用后保存到设备；若要保留为自定义模板，请点击“保存到当前模板”并新建模板。自定义模板确认后可直接保存当前网页设置，无需先应用。新建模板不会自动切换活动模板。

KEY MAPPING

按键映射

从菜单选择键盘或鼠标动作，也可监听键盘录入。

12 路按键

面板布局：上排左侧 BT8～BT5，右侧 BT4～BT1；下排 BT9 / BT10。P1 / P2 为旋钮按压，分别位于布局左上 / 右上。

连接设备后读取十二路键位，或在实验性功能中打开模拟演示。

允许重复映射。监听时 Esc 取消；Esc 键可从菜单选择。重复键按下会重触发，可能短暂中断原有长按。

LIGHTING

灯光设置

设置灯效模式、亮度及全局颜色。

亮度 100 对应实际最高 50%。逐键配色与模式灯在实验性功能中。

KNOBS

旋钮设置

模拟旋转，观察当前位置、累计圈数和输出方向；修改输出轴、方向及倍率。

等待设备能力

本地模拟用于预览倍率与方向；实际设备旋钮状态位于输入测试模块。U4 / FPC1、U5 / FPC2 对应旋钮小板，左右位置需根据实际装配确认。输出范围、PUSH 过滤与来源接管在实验性功能中。

INPUT STATUS

输入测试

查看物理按键、旋钮按压与设备旋钮状态；修改绑定请使用按键映射模块。

物理状态 · 约 2Hz
长按设备按键 → 显示按下状态短按可能落在两次快照之间；网页不据此判断漏采。

等待连接。状态快照约 2Hz，无法判断毫秒级漏采；PUSH 以设备能力为准。

FIRMWARE

固件更新

检查 UF2 文件，进入下载模式并手动复制，重连后核对版本。

01保存配置

更新前应用并保存需要保留的配置。

02进入下载模式

按住 SW2 / BOOT 插入 USB 后松开。出现 RPI-RP2 盘后复制正确的新板 UF2。

03重新连接

核对设备身份与版本，再做实板功能验证。

整合固件支持进入 ROM UF2 下载模式及保存后的 USB 冷切换；结构检查不等于升级成功。

等待更新后重新握手确认版本。

扫描与重触发

灯光 · 逐键配色与模式灯

自动配色保留已存逐键 RGB；GP11 独立指示灯暂定实际 25%，由固件单独限幅。

滑轨 · 输出范围与滤波

调整输出范围与信号滤波；共享校准在下方“运动”分组中。校准使用实测行程，失败或取消保留旧记录。

连接支持运动遥测的设备后，显示三路 ADC、滑轨位置与信号质量。
旋钮 · 输出范围与 PUSH 防误触

连接设备后读取两路旋钮的输出范围与 PUSH 过滤参数，或在连接分组中打开模拟演示。

HID count 不等于屏幕像素；磁环和 PUSH 结构尚未实板验证。

来源接管 · 同轴策略
