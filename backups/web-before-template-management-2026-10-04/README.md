## 使用与设备真值

1. 连接 → CDC DTR=true → hello核对产品/板型/协议/scope/能力 → get_status/get_device/list_profiles/get_profile一致revision读回。
2. 编辑十二路绑定、灯与motion配置形成网页草稿。支持标准键位菜单、电脑键盘监听、US单字符与高级usage/modifiers；长按repeat忽略，Esc/失焦取消监听，重复键允许。颜色按BT保存。
3. “应用编辑到RAM”发送完整set_profile（旧runtime固件发set_config），等待公共两核ACK后再次读回；不把按钮点击当成功。非活动模板编辑不会自动激活；切换活动模板用独立按钮。
4. “保存到设备”调用save_config，12秒超时，等维护完成及读回。完整保存元数据可在实验性功能的原始状态中查看；主区显示保存状态。网页关闭不自动保存，设备普通运行不依赖网页。
5. 任意写操作出错后先完整读回；会话超时/断线/错误id/错误协议关闭会话，取消排队请求。已经接受的设备操作仍可能继续，重连读回后再决定，不盲重试save/boot/import。

设备字段与范围唯一来源：`../firmware/FluxRail/src/protocol/CDC_PROTOCOL.md`和`../docs/spec/12_完整配置与Flash序列化.md`。网页只作适配与前置校验，固件仍负责最终校验。请求ASCII/4096字节；串行队列最多8，普通2秒、配置4秒、保存12秒。响应缓冲4096，超长丢到LF；设备schema1目前没有异步事件，意外/不匹配响应终止会话。后续事件必须冻结公共格式再加接收分流。

## 模板、保存与快照

预置ID1～4不可删除、自定义最多8个，总12。名称1～31可打印ASCII且不能包含引号/反斜杠。新增复制选定模板，读回后自动选中新ID供编辑，保持不自动激活。“修改模板”导航到所选模板的按键设置；灯光、滑轨、旋钮同属该模板，修改后需应用到RAM并按需保存。有草稿时模板切换/增删改名/恢复/激活禁用，修改入口仍可继续编辑；活动自定义删除由设备原子切回4。音击默认两旋钮关闭，不编造游戏键位。

导出全部配置以设备export_config字节为真值，逐块检查revision/length/CRC/offset，保留binary32/64和校准精度，不从网页表单重编码真实快照。JSON文件封套只含产品、板型、序号、固件、现有schema/encoding/length/crc32/data；data是公共hex-le-schema1字节，未另建设备存储格式。

导入在本地先检查产品/板型/schema/长度/CRC、模板ID/数量/字段/范围、校准结构，呈现全部模板/活动ID/校准/来源设备预览。确认拟变更后begin_import、512字节顺序chunk、commit_import；固件再做完整校准曲线/覆盖/语义验证并原子应用，仍只RAM。跨安装校准需用户核对机械。现有协议只支持全包，不伪装支持current/all/calibration分scope传输。导出操作会取消设备未完成import，因此页面忙时不混发这两种操作。

## 实验室 IO4 映射编辑（2026-10-03）

普通 USB 身份连接并读回设备，在模板区选择待编辑模板，展开“实验性功能 → IO4 · 按键功能映射”。十二路卡片按物理顺序显示，选择左/右 A、B、C、菜单、侧键、Test、Service或禁用。下方显示设备读回值及未应用草稿；编辑的是该模板的 IO4 功能表，普通键盘字母/鼠标表独立保留。

操作顺序：修改 → 应用 IO4 映射到 RAM → 如尚未激活则“将本模板设为活动” → 更新区选择 IO4 并“应用启动身份到 RAM” → 保存到设备 → 重启到已保存身份。启动身份应用后必须再保存，即便此前保存过映射。IO4默认无CDC，按住BT10/GP9复位或上电返回普通再连接。重复功能按 OR 持有，BT10恢复入口不受自定义功能影响。

未应用的IO4草稿会阻止共享写操作、保存、模板切换、USB身份、校准和UF2；可继续修改或点“读回映射（舍弃草稿）”。普通配置有草稿时先应用/读回，再编辑IO4。外部revision冲突禁止写入，不盲重试。所有写操作复用set_io4_bindings/set_active_profile/save_config与既有USB冷切换，未另建存储或协议。

本轮Web33项、ARM IO4 22组67513原始检查通过，包含普通编辑→保存→重建IO4按键报告验证。固件源码和阶段4正式UF2均未改变，无需因网页更新重新刷已部署整合固件。浏览器仅验证真实布局/断连锁定，无实板或游戏验证。证据../tests/integration/validation_io4_editor_2026-10-03.json；完整原构建证据仍见validation_integration_2026-10-03.json，其Web30项是历史版本。
